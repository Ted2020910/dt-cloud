# 「使用AI」的定义

## 已知前提

目标是用 AI 生成一份优秀的 PPT，需要先对目标中每个词建立共识。

## 认知起点

「使用 AI」这个词的边界是什么？是泛指所有 AI 工具，还是特指某种技术形态？

## 推导逻辑

用户明确说明：
- AI 指的是调用大模型接口（如 Claude、GPT 等）
- 输入是多模态的：可以是图片、文件、文字
- 输出方式：模型通过 Tool Use（工具调用）来完成任务
- 工具是**自定义的**，不是已有的第三方 PPT 工具
- 目标是**端到端全自动**生成 PPT，AI 负责整个流程

因此「使用 AI」的本质是：**以大模型为核心 Agent，通过自定义工具链驱动整个 PPT 生成流程**。

## 讨论共识

✅ AI = 调用大模型接口（Claude / GPT 等）
✅ 输入：多模态（文字 / 图片 / 文件）
✅ 输出：通过 Tool Use 调用自定义工具
✅ 模式：端到端全自动，AI 主导整个流程
✅ 工具：自定义，非现成第三方工具
