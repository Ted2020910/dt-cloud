# OCMT参考方案：jomafilms/openclaw-multitenant

## 已知前提

- 002 节点确认 OpenClaw 官方不支持多租户
- 用户希望了解现有的多租户开源实现

## 认知起点

找到 `jomafilms/openclaw-multitenant`（OCMT）项目，这是目前最完整的 OpenClaw 多租户开源实现。

### 关键特性

| 特性 | 实现方式 | 评估 |
|------|---------|------|
| **容器隔离** | 每个用户独立 Docker 容器 | ⭐⭐⭐ 强 |
| **加密 Vault** | AES-256-GCM + Argon2id | ⭐⭐⭐ 强 |
| **团队 Vault** | N-of-M 阈值解锁 | ⭐⭐⭐ 好 |
| **MFA** | TOTP 多因素认证 | ⭐⭐⭐ 完整 |
| **审计日志** | 全平台活动追踪 | ⭐⭐⭐ 完整 |
| **RBAC** | 基于角色的访问控制 | ⭐⭐ 中等 |
| **抽象 Agent** | 只支持 OpenClaw | ❌ 不支持 |

### 与我们方案的对比

| 维度 | OCMT | 我们方案 |
|------|------|---------|
| **隔离层** | Docker 容器 | 文件系统 + OS ACL |
| **复杂度** | 高 | 低 |
| **适用规模** | 100+ 人 | 30-50 人 |
| **成本** | 高（需要 Docker/K8s） | 低 |
| **Skill 共享** | 团队功能 | system/teams/tenants 三层 |
| **抽象 Agent** | ❌ 只支持 OpenClaw | ✅ 支持多 Agent 底座 |

## 讨论共识

**OCMT 是目前最完整的 OpenClaw 多租户实现**，但：

1. **基于 Docker 容器** - 复杂度高，需要 K8s 或 Docker Swarm
2. **只支持 OpenClaw** - 不支持 Hermes/Claude Code 等其他 Agent
3. **资源开销大** - 每个用户一个容器，30-50 人规模有点浪费

**我们可以借鉴的部分**：
1. Vault 加密方案（AES-256-GCM + Argon2id）
2. 容器休眠/唤醒机制
3. N-of-M 团队 Vault 阈值解锁
4. 审计日志设计
5. MFA 多因素认证流程

**仓库地址**: `https://github.com/jomafilms/openclaw-multitenant`
