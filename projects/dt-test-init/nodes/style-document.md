# 写作风格：document（记录/存档）

## 适用场景

当你需要客观记录事实、存档代码分析结果、整理调研笔记、或保存原始材料时，使用 document 类型。

## 写作要点

- **客观记录**：尽量区分事实描述和主观判断，事实放前面，判断明确标注
- **信息来源**：注明信息从哪里来的（代码文件、文档、对话、观察）
- **结构化呈现**：善用表格、列表、代码块让信息可扫描
- **避免遗漏关键细节**：宁可多记，后续可以裁剪
- **时间标记**：如果信息有时效性，标注记录时间

## 参考结构

```
概述：一句话说明记录了什么
详细内容：按逻辑分组的事实记录
来源：信息从哪来的
备注：补充说明或需要注意的点
```

*注：以上结构仅供参考，可根据实际情况自由调整。*
