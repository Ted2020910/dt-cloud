# 写作风格：decision（决策/选择）

## 适用场景

当你需要在多个方案中做出选择、记录一个权衡过程、或归档一个已做出的决定时，使用 decision 类型。

## 写作要点

- **列出选项**：有哪些可选方案？每个方案的核心思路是什么？
- **权衡分析**：每个方案的优劣势，用对比表或 pros/cons 展示
- **记录决策理由**："为什么选这个"比"选了什么"更重要
- **记录否决理由**：被排除的方案为什么不行，避免将来重复讨论
- **标注决策条件**：如果前提变了，这个决策是否需要重新审视？

## 参考结构

```
决策背景：为什么需要做这个选择
选项列表：各方案简述
对比分析：优劣势对比（表格或列表）
最终选择：选了什么，为什么
否决记录：排除了什么，为什么
前提条件：这个决策依赖哪些假设
```

*注：以上结构仅供参考，可根据实际情况自由调整。*
