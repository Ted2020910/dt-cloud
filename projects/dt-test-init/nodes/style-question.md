# 写作风格：question（问题/任务定义）

## 适用场景

当你需要提出一个待解决的问题、定义一个讨论话题、或明确一个任务的边界时，使用 question 类型。

## 写作要点

- **明确问题本身**：这个问题到底在问什么？用一句话说清楚
- **交代背景**：为什么需要回答这个问题？它从哪里来？
- **划定边界**：这个问题讨论什么、不讨论什么、到什么程度算"回答完了"
- **列出已知约束**：已经知道的限制条件、前提假设
- **标记不确定性**：哪些地方你还没想清楚，需要进一步探索

## 参考结构

```
问题描述：一句话说清楚要解决什么
背景/动机：为什么需要回答这个问题
边界：讨论什么 / 不讨论什么
已知约束：已确认的限制条件
开放点：还不确定的部分
```

*注：以上结构仅供参考，可根据实际情况自由调整。*
