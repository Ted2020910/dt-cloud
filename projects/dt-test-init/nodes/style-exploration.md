# 写作风格：exploration（探索/发散）

## 适用场景

当你还在摸索、没有明确结论、需要发散思考、或者只是想把想法记下来时，使用 exploration 类型。

## 写作要点

- **允许不完整**：探索节点不需要有结论，记录思路比得出答案更重要
- **标记方向**：当前在往哪个方向想？为什么觉得这个方向值得探索？
- **记录岔路**：想到了但没有深入的方向也记下来，留给将来
- **显式标记不确定性**：哪些是猜测、哪些是初步判断、哪些需要验证
- **保持时间线**：探索往往是渐进的，记录思路的演变过程

## 参考结构

```
探索方向：在想什么、为什么想这个
当前思路：目前的想法和推测
待验证：需要进一步确认的假设
岔路记录：想到但暂未展开的方向
```

*注：以上结构仅供参考，可根据实际情况自由调整。*
